# Statik Dijital Kartvizit / Portfolyo Sitesi

Bu proje, **GitHub Pages** üzerinde tamamen ücretsiz ve ek bir sunucuya ihtiyaç duymadan barındırılabilmesi için saf **HTML, CSS ve JavaScript** kullanılarak hazırlanmıştır.

## İçerik
- `index.html`: Ana sayfa iskeleti (Tailwind CSS CDN ile hızlı ve modern tasarım).
- `style.css`: Ek stil tanımlamaları.
- `script.js`: Tema değiştirme (koyu/açık mod) ve dinamik yıl scriptleri.

## GitHub Pages'e Yükleme Adımları
1. Bu dosyaları bir GitHub deposunda (`repository`) yayınlayın.
2. Deponun **Settings** -> **Pages** sekmesine gidin.
3. **Build and deployment** bölümünde Source kısmını **Deploy from a branch** olarak seçin.
4. Branch olarak `main` (veya `master`) ve klasör olarak `/ (root)` seçip **Save** deyin.
5. Birkaç dakika içinde siteniz `https://kullaniciadiniz.github.io/depoadi` adresinde yayında olacaktır!
